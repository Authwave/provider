Integration guide

PHP integration example

Illustrative configuration using a demo deployment. Replace the demo values when connecting your client.

use Authwave\Authenticator;
require __DIR__ . "/vendor/autoload.php";

// Keep the real deployment client key in your server environment.
$clientKey = getenv("AUTHWAVE_CLIENT_KEY");
$auth = new Authenticator(
    $clientKey,
    "https://client.example.test" . $_SERVER["REQUEST_URI"],
    "login.example.test",
);

if (isset($_GET["login"])) {
    $auth->login();
} elseif (isset($_GET["logout"])) {
    $auth->logout("https://client.example.test/");
}

if ($auth->isLoggedIn()) {
    // Display your authenticated application content.
}

Connect a client

  1. Create an application and choose a deployment.
  2. Copy the provider host, deployment ID and API key into your server configuration.
  3. Set the client URL and login callback path.
  4. Redirect sign-in requests through the Authwave client.
  5. Handle the encrypted callback, create your application session and test logout.
